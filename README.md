This project is a conversational AI chatbot built using Streamlit and the Groq API. The chatbot maintains conversation history throughout a user session, allowing context-aware interactions with a LLM.

Features
- Streamlit web interface
- Official Groq Python SDK integration
- Secure API key management using Streamlit Secrets
- In-memory conversation history using st.session_state
- Context-aware responses by sending previous messages with each request
- Reset Conversation button
- Chat-style user interface
Technologies Used
- Python
- Streamlit
- Groq Python SDK
- Llama 3.1 8B Instant
